# Pure Java HTTP Server

Многопоточный HTTP-сервер на Java** без использования внешних библиотек или фреймворков (таких как Spring или Netty). 

## ⚡ Особенности
- 🚀 **Без зависимостей**: Только стандартная библиотека Java (JDK).
- 🧵 **Многопоточность**: Каждое клиентское соединение обрабатывается в отдельном потоке.
- 🛣️ **Базовая маршрутизация**: Поддержка разных путей (`/`, `/hello`, `/health`) и методов (с проверкой на `GET`).
- 📝 **Парсинг запросов**: Чтение строки запроса и HTTP-заголовков.
- ✅ **Корректные ответы**: Формирование валидных HTTP-ответов с кодами состояния (200, 400, 404, 405) и заголовками (`Content-Type`, `Content-Length`).

## 🛠️ Требования
- **Java 15 или выше** (в коде используются текстовые блоки `"""` и улучшенные `switch`-выражения).
